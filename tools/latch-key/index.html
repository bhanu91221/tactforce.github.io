Overview

Latchkey is a software passkey authenticator. It intercepts a site's WebAuthn request and signs it locally, using a PIN-encrypted seed that never leaves your device — no physical security key, no background daemon to install and keep running.

It's built for the Salesforce login passkey flow: once installed and set up, it steps in whenever Salesforce asks your browser for a passkey, so you can approve the request with one click (or your PIN after the extension has been idle) instead of reaching for a hardware key.

How it works

  1. A content script running in the page overrides navigator.credentials.create() and navigator.credentials.get() on Salesforce and Force.com login pages, so passkey requests are routed to Latchkey instead of a physical authenticator.
  2. The request is handed off to Latchkey's background service worker, which acts as the authenticator — it opens its own approval popup so you can confirm the request is expected.
  3. On approval, a P-256 key pair is generated and the private key is wrapped and encrypted inside the credential ID itself. Nothing is written to a per-site credential store — the encrypted key travels with the credential, held by the relying party (Salesforce).
  4. Signing happens locally via the browser's WebCrypto API, and the relying party receives back an ordinary PublicKeyCredential — from Salesforce's side, it looks exactly like any other passkey.

First-time setup & recovery

  • After installing, open the Latchkey icon in your browser toolbar and set a PIN — it's used to encrypt your local seed and to re-approve requests after the extension has been idle for a while.
  • Latchkey generates a single 24-word BIP-39 recovery phrase. Write it down and store it somewhere safe — it's the only way to recover access if you lose the device or need to move to a new one.
  • From then on, registering or signing in with a passkey on a supported Salesforce login page will prompt a Latchkey approval popup instead of asking for a hardware key.

Good to know

Permissions: storage only Scope: Salesforce / Force.com login pages Version 0.3.0
  • Latchkey only requests the storage permission — it doesn't need network access to do its job.
  • It currently targets Salesforce and Force.com domains (plus localhost for development); it isn't a general-purpose passkey manager for arbitrary sites yet.
  • There's no per-site credential database to back up or lose — each key lives encrypted inside its credential ID on the relying party's side. Your 24-word recovery phrase is what re-derives access if a device is lost.
Runs entirely on your device. Latchkey signs locally in the browser using WebCrypto. There's no companion server and no cloud sync — the only thing standing between your seed and the outside world is your PIN and your recovery phrase.
