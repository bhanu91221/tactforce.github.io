Permission Dependency Extractor

All Tools

Generate the PermDepMap.json static resource for your org.

How it works

  1. Open Workbench, Salesforce Inspector, or any REST client authenticated to your org.
  2. Call this Tooling API endpoint with a GET request:
    /services/data/v66.0/tooling/query/?q=SELECT+Permission,PermissionType,RequiredPermission,RequiredPermissionType+FROM+PermissionDependency
  3. Copy the entire raw JSON response and paste it into the text area below.
  4. Click Generate JSON.
  5. Click Download, then upload the file as a static resource named PermDepMap in your org.
